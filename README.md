# 她自己的天堂

独立的插件，不依赖也不修改任何其它插件。

## 为什么做这个

「温柔一点」这句话，模型听不懂。它能听懂的是**具体动作**。

所以这插件不复述形容词，只做五件能测出来的事：

### 1. 知道他现在累不累

从他自己的话里认：累 / 困 / 熬夜 / 忙 / 加班 / 难过 / 委屈 / 感冒 / 发烧 / 开心……

认出之后，注入变成：

```
【这会儿怎么相处】
- 他现在累，别抛问题，别让他解释，话短一点
```

状态**3 小时**后自动失效（可调），不会一直当他累着。

### 2. 不连着追问

数她最近 15 分钟里的问号（可调窗口和上限）。超了就说：

```
- 最近你问得有点多了，这轮只回应他说的，不要再抛问题
```

### 3. 小事不纠正

```
- 他说错的小事别当场纠正，听着往下接；要紧的事轻声问一句就行
```

留体面，但不当老好人——**要紧的事还是要说，只是换个说法**。

### 4. 话头（收场前留半句）

她一旦说「先不聊了 / 去睡了 / 上课了」这种收场的话，插件就把他上一句存成一条**话头**。

下次他开口，注入里会多一句：

```
- 上次他没说完的是「那部片子我还没看完」，这次可以先接这个
```

话头可以在面板上手动划掉（「已接」）。

> 这是「不提前退场」的落地版本：她可以困，但不会替你把话说完。

### 5. 语气簿

记他说话的语气：轻 / 急 / 笑 / 疲 / 凶（带原句）。下次相关的时候提一句：

```
- 上次他说「算了，没事」的时候语气是「轻」，你记着这个
```

### 6. 慢一点

回复前按长度停顿（0.35 秒起，每字加一点，上限可调）。秒回一大段天生不温柔。

## 面板

**概览**：每个人一张卡，上面是「状态 · 多久之前」「近期几个问号」，下面是挂着的话头（可划掉）和语气簿。

**设置**：六个开关 + 五个数值，保存即时生效。

## 数据

`data/plugin_data/astrbot_plugin_paradise/paradise.json`，按 QQ 分开存；删掉即可重建。

## 可移植性

- 不 import 别的插件，不读别的插件文件
- 全新安装从零开始，聊天自然积累
- 所有阈值在 `settings.json`（面板可调）
- 注入用 `TextPart(...).mark_as_temp()`，**不改 system_prompt**

## 提醒

这插件会让她**少问问题、少纠正、慢一点**。如果你更想要一个话多、反应快、随时接梗的助手，把对应开关关掉就行——每条都是独立的。
